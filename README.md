# App-Discovery-ISC
una aplicacion universitaria diseñada para nuevos estudiantes interesados en la carrera de ISC u otras,
incluye elementos didacticos, y de interes para los jovenes ,
contiene un pequeño quiz para determinar si te puede gustar la carrera o no,
e informacion y testimonios sobre otras carreras por si ISC no es lo tuyo
